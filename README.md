# Windows Health Check Dashboard

Lightweight local system health checker for Windows endpoints.

## About

A practical monitoring tool for system metrics and a simple web dashboard.

## Tech stack

- Python
- FastAPI
- psutil

## Run locally

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

## Check

Open: http://localhost:8000

## Notes

Best run locally first on Windows.
